Como Configurar e Executar

Siga o passo a passo abaixo para rodar a aplicação localmente.

Pré-requisitos

Certifique-se de ter o Python 3.x instalado e uma instância do PostgreSQL ativa (local ou em nuvem).

1

Clonar o Repositório

git clone https://github.com/mrjackxxz/meus-projetos
2

Instalar as Dependências

pip install customtkinter psycopg2-binary bcrypt python-dotenv
3

Variáveis de Ambiente (`.env`)

Crie um arquivo chamado .env na raiz do projeto e insira suas credenciais:

DB_HOST=seu_host_aqui
DB_USER=seu_usuario_aqui
DB_PASS=sua_senha_aqui
DB_NAME=seu_nome_do_banco_aqui
DB_PORT=5432
4

Executar o Aplicativo

python main.py
